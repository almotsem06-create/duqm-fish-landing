نظام تسجيل إنزال الأسماك في الدقم - المرحلة الخامسة
======================================================
الإضافات:
1. المحضر الرسمي لكل عملية إنزال مع صفحة طباعة مستقلة.
2. رفع صور/ملفات PDF للمحضر.
3. سجل المحاضر مع البحث برقم الإنزال أو السفينة والتاريخ.
4. تقارير وإحصائيات إجمالي الكميات والكميات حسب نوع السمك.
5. إضافة الموظفين من حساب المدير.
6. كلمات المرور أصبحت مشفرة بدلاً من التخزين كنص صريح.
7. تشغيل بدون وضع debug.

التشغيل:
- ثبّت Python 3.10+.
- افتح الطرفية داخل المجلد.
- نفّذ: pip install flask werkzeug
- ثم: python app.py
- افتح المتصفح على http://127.0.0.1:5000

الحسابات التجريبية:
admin / admin123
inspector / inspect123
viewer / view123

ملاحظة: هذه نسخة تشغيلية أولية. قبل النشر الرسمي على الإنترنت يفضل إضافة HTTPS، جلسات دخول آمنة، نسخ احتياطي للقاعدة، وإدارة صلاحيات أدق.


المرحلة السادسة:
- تصميم رسمي للمحاضر والتقارير.
- فلاتر التقارير حسب الفترة ونوع السمك.
- جدول تفصيلي للمحاضر داخل التقرير.
- منطقة توقيع المفتش واعتماد المسؤول.
- تهيئة أفضل للطباعة.
- مكان مخصص للشعار الرسمي؛ يستبدل عند تزويدنا بملف الشعار.

المرحلة السابعة:
- استخراج المحضر مباشرة بصيغة PDF.
- زر PDF داخل سجل المحاضر.
- تنسيق PDF رسمي يتضمن بيانات السفينة والرحلة والكمية وأنواع الأسماك والمفتشين والتوقيعات.
- تحسين واجهة النظام وإظهار رقم الإصدار.
- تم الحفاظ على إمكانية الطباعة والمرفقات والتقارير والبحث.

المرحلة الثامنة:
- نسخ احتياطي لقاعدة البيانات من حساب المدير.
- حذف المحاضر للمدير فقط مع تأكيد قبل الحذف.
- دعم ترقية قاعدة البيانات القديمة بإضافة بيانات التوقيع دون فقد البيانات.
- معلومات إصدار النظام والجهة والوحدة.
- تحسين إدارة البيانات قبل الانتقال للنشر الفعلي.

المرحلة التاسعة:
- حالات المحضر: مسودة / مراجعة / معتمد.
- اعتماد إلكتروني متعدد للمفتشين.
- سجل بيانات السفن (رقم، اسم، مالك، ترخيص، ملاحظات).
- إدارة بيانات السفن من المدير.
- إظهار حالة المحضر في سجل المحاضر.
- تجهيز النظام لمرحلة النشر الفعلي والربط بقاعدة بيانات مركزية.
