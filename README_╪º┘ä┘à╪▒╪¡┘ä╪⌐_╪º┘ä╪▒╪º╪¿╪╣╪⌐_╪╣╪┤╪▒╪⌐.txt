المرحلة الرابعة عشرة – لوحة المدير المتقدمة

الجديد:
- لوحة إحصائيات خاصة بالمدير.
- إجمالي الموظفين والحسابات المفعلة.
- إجمالي الإنزالات وقيد المراجعة والمعتمدة.
- عدد التفويضات النشطة.
- تفعيل وتعطيل حسابات الموظفين.
- إعادة تعيين كلمة مرور أي موظف من المدير.
- تسجيل عمليات الإدارة في سجل العمليات.
- الحساب المعطل لا يستطيع تسجيل الدخول.

ملاحظة:
هذه نسخة تطويرية جاهزة لاستكمال تأمين النشر. يجب تغيير الحسابات الافتراضية وضبط SECRET_KEY وHTTPS وقاعدة البيانات المركزية قبل الاستخدام الفعلي.
